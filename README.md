# 📊 Sales Analysis Dashboard - Power BI

## 📌 Overview

This project presents an **interactive Power BI dashboard** designed to analyze sales performance, customer behavior, and product trends.

The dashboard provides insights across multiple time dimensions (year, quarter, month, day) and helps businesses make data-driven decisions.

---

## 🎯 Objectives

* Analyze sales trends over time
* Understand customer purchasing behavior
* Identify top-performing categories
* Evaluate sales performance across different segments

---

## 📊 Dataset

The dataset contains customer shopping data, including:

* Sales Amount
* Customers
* Quantity
* Date (Year, Quarter, Month, Day)
* Category
* Gender

📁 File: `data/customer_shopping_data.csv`

---

## 📈 Key KPIs

* 💰 Total Sales
* 👥 Total Customers
* 📦 Total Quantity
